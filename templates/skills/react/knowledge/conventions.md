# react — Conventions

Naming and structural conventions for react.

---

- Name components with PascalCase: `UserProfile`, not `userProfile`
- Name hooks with `use` prefix: `useAuth`, `useFetch`
- One component per file, filename matches component name
- Colocate styles, tests, and types with the component
- Prefer function components with hooks over class components
- Use TypeScript interfaces for props: `interface UserCardProps { ... }`

---

_Customize these conventions based on your team's preferences._
