# tailwindcss — Conventions

Naming and structural conventions for tailwindcss.

---

- Use `cn()` or `clsx()` for conditional class merging
- Mobile-first: start with base styles, add responsive prefixes
- Group utilities logically: layout → spacing → typography → colors → effects
- Extend theme in tailwind.config for project-specific tokens
- Use dark: prefix for dark mode variants

---

_Customize these conventions based on your team's preferences._
