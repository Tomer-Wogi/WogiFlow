## Risk + mitigation

- **H1 is critical-path for C2 + E.** Adversary flagged 1-week estimate as optimistic; budgeted 1-2 weeks. If H1 slips, C2/E slip.
- **F2 migration (flat skills → directory-per-skill)** touches user data — requires backward-compat shim for ≥1 release so existing user skills keep working during migration.
- **G3 (SQLite IPC)** changes workspace coordination contract — requires multi-worker integration test before landing.
- **B1-B6 false-positive risk** mitigated by B7 telemetry baseline shipping first; if any B-story's missRate exceeds catch-rate by more than 3×, that gate converts from hard-block to soft-warning until evidence improves.

## Rollout safety

- All changes opt-in via `config.json` feature flags during the release, default-off for any behavior-changing gate.
- Release note explicitly calls out migration steps (F2 skills dir, G3 message-bus format).
- Rollback plan: feature flags off + git revert the commit; no data-destructive migrations without backup.
