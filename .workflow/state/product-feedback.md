# WogiFlow Product Feedback

Product-level learnings that should improve WogiFlow for ALL users. These are distinct from project-level `decisions.md` which contains rules specific to one project.

**When to write here vs decisions.md:**
- A bug in how `/wogi-*` commands behave → HERE (product)
- A convention for your team's code style → `decisions.md` (project)
- An improvement to WogiFlow's task execution pipeline → HERE (product)
- A rule about your project's file structure → `decisions.md` (project)

**Lifecycle:** Entries here are reviewed by the WogiFlow team and incorporated into base code (commands, scripts, templates, hooks). Once a fix ships, the entry is marked SHIPPED.
