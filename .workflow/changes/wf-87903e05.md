# [wf-87903e05] Enhance research protocol with Phase 6 and comparison question type

## User Story
**As a** WogiFlow user doing research
**I want** the research protocol to include Phase 6 (Recommendation Verification) and detect comparison questions
**So that** I always get verified recommendations that don't duplicate existing functionality

## Description
The research protocol currently has 5 phases. Phase 6 was added to the hook (`research-gate.js`) but not the core module. Additionally, comparison questions ("What can we learn from X?") need to be recognized as a distinct question type that triggers the full 6-phase protocol. This ensures any WogiFlow user doing research gets properly verified answers.

## Acceptance Criteria

### Scenario 1: Comparison questions are detected
**Given** a user asks "What can we learn from X for Y?" or similar comparison question
**When** the question classifier runs
**Then** it should detect type `comparison`
**And** suggest `deep` depth (comparison research needs thorough verification)

### Scenario 2: Phase 6 tracked in session
**Given** a research session is created
**When** the session phases are initialized
**Then** Phase 6 `recommendationVerification` should be included
**And** it should track status like other phases

### Scenario 3: Protocol documentation includes Phase 6
**Given** the `/wogi-research` command documentation
**When** a user reads the documentation
**Then** they should see Phase 6: Recommendation Verification
**And** understand when it applies (comparison research)

### Scenario 4: Core module header documents Phase 6
**Given** the `flow-research-protocol.js` file
**When** a developer reads the module header
**Then** Phase 6 should be listed with the other phases

### Scenario 5: Recommendation verification enforced
**Given** a comparison research session produces recommendations
**When** Phase 6 runs
**Then** each recommendation MUST have verification evidence:
  - Search patterns used
  - Files read
  - Status: EXISTS/PARTIAL/MISSING
**And** only MISSING recommendations are presented

## Technical Notes
- **Components**:
  - Modify: `scripts/flow-research-protocol.js` - Add Phase 6 to session, add comparison question type
  - Modify: `.claude/commands/wogi-research.md` - Document Phase 6
  - Already done: `scripts/hooks/core/research-gate.js` - Phase 6 injection (from wf-085f189d)
- **New question patterns for comparison**:
  ```javascript
  comparison: [
    /\bwhat\s+can\s+(we|i)\s+learn\s+from/i,
    /\bwhat\s+does\s+[\w\s]{1,50}\s+do\s+(better|differently)/i,
    /\bhow\s+does\s+[\w\s]{1,50}\s+compare\s+to/i,
    /\bwhat\s+(features?|patterns?)\s+from\s+[\w\s]{1,50}\s+should/i
  ]
  ```
- **Phase 6 in session**:
  ```javascript
  recommendationVerification: { status: 'pending', completedAt: null, recommendations: [] }
  ```
