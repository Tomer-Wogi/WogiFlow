## User Story

As a team lead, I want aggregated model intelligence across my team and the ability to export high-value observations, so that the team benefits from shared model learnings and accumulated knowledge.

## Description

Extends community model intelligence (Phase C1-C2) with team-level aggregation. Team members' model adapter learnings are aggregated and shared. Also adds a `flow memory export-team` command concept for extracting high-value observations from local memory to team-level knowledge.

## Acceptance Criteria

### AC1: Team Model Intelligence Aggregation API
Given a team with multiple members using model adapters
When model learnings are synced
Then:
- `GET /api/teams/:teamId/model-intelligence` — Aggregated model learnings across team
- Groups by model_name, learning_type
- Shows: model name, learning count, top adjustments, top corrections, contributed_by count
- Extends existing `model_learnings` table from T3-S3 (knowledge sharing)
- Merges community model intelligence (from `global_knowledge` where category='model_intelligence') with team-specific learnings

### AC2: Team Model Intelligence Dashboard
Given the team dashboard
When a team member views model intelligence
Then:
- `/knowledge.html` extended with "Model Intelligence" tab
- Table/cards showing per-model stats: name, team learnings count, community learnings count
- Expandable detail: list of adjustments, corrections, strengths for each model
- "Adopt Community Learning" button → promote to team knowledge (uses AC from S5)

### AC3: Memory Export API
Given a team member with local observations
When they want to share high-value observations
Then:
- `POST /api/teams/:teamId/memory/export` — Submit observations from local memory (body: { observations: [{ category, content, tags, confidence }] })
- Observations go through validation: strip PII, validate category, check for duplicates against existing team knowledge
- Creates entries in `team_shared_configs` with config_type='memory_observation' or a new dedicated table
- Team admins can review exported observations on the dashboard

### AC4: Memory Export Dashboard Section
Given the team dashboard
When an admin views exported memories
Then:
- "Team Observations" section on knowledge page
- List of exported observations: category, content preview, contributor (anonymized?), date
- Accept/dismiss actions for admin review
- Accepted observations become team knowledge entries

### AC5: Statistics + Insights API
Given team model usage data
When analytics are queried
Then:
- `GET /api/teams/:teamId/model-intelligence/stats` — Summary stats
- Response: { models: [{ name, teamLearnings, communityLearnings, topAdjustment }], totalObservations, topContributors: [{ userId, count }] }
- Extends existing analytics patterns from T4-S6
