# Remove Teams Implementation from Public Repo

**ID:** wf-e28a6f68
**Type:** story
**Feature:** security
**Priority:** P0
**Created:** 2026-02-25

## User Story

As the WogiFlow maintainer, I want Teams implementation code removed from the public MIT-licensed repo, so that paid feature source code is not freely visible/downloadable.

## Description

The public `wogi-flow` repo contains 3 files with complete Agent Teams implementation (lead detection, teammate state tracking, file conflict detection, task dispatch). These belong in the private `wogiflow-cloud` repo. Generic extension infrastructure (extension-registry, postinstall detection, config stubs) stays.

## Acceptance Criteria

### AC1: Delete 3 Teams implementation files
**Given** the public repo contains flow-agent-teams.js, teammate-idle core hook, and teammate-idle entry hook
**When** the cleanup is applied
**Then** all 3 files are deleted from the repo

### AC2: Remove Teams consumer code from 4 core hooks
**Given** flow-parallel.js, session-context.js, task-gate.js, and task-completed.js import from flow-agent-teams
**When** the cleanup is applied
**Then** all require() calls and try-catch blocks referencing flow-agent-teams are removed, keeping only fallback logic where applicable

### AC3: Remove TeammateIdle hook registration from settings
**Given** .claude/settings.json has a TeammateIdle hook entry
**When** the cleanup is applied
**Then** the TeammateIdle hook registration is removed

### AC4: Remove agentTeams config and schema
**Given** config.json has agentTeams section and teammateIdle hook rule
**When** the cleanup is applied
**Then** both config sections are removed, and config.schema.json agentTeams definition is removed

### AC5: Update documentation references
**Given** wogi-status.md, claude-code-compatibility.md reference Agent Teams
**When** the cleanup is applied
**Then** Agent Teams references are removed from documentation

### AC6: All JS files pass syntax check after cleanup
**Given** edits were made to multiple JS files
**When** node --check is run on each
**Then** all pass without errors

### AC7: Config JSON files remain valid
**Given** config sections were removed
**When** JSON.parse is run on config.json and config.schema.json
**Then** both parse without errors

## Boundaries

- Do NOT remove extension-registry.js (generic infrastructure)
- Do NOT remove postinstall extension detection (generic)
- Do NOT remove team config stub (enabled: false, projectId, orgId) — that's a placeholder for the paid package
- Do NOT modify request-log.md historical entries (history is immutable)

## Files to Delete
- scripts/flow-agent-teams.js
- scripts/hooks/core/teammate-idle.js
- scripts/hooks/entry/claude-code/teammate-idle.js
