# [wf-0d039921] Add Claude Sonnet 4.6 to model registry

## User Story
**As a** WogiFlow user running Claude Sonnet 4.6
**I want** the model to be recognized by the model registry
**So that** routing, stats, and prompt adaptation work correctly for this model

## Description
Claude Code 2.1.45 added support for Claude Sonnet 4.6. WogiFlow's model adapter and providers files need to recognize this model for pattern matching, capability lookup, and model selection lists.

## Acceptance Criteria

### Scenario 1: Model pattern recognition
**Given** a user is running Claude Sonnet 4.6
**When** the model adapter identifies the current model
**Then** it matches to the `claude-sonnet` family via `claude-sonnet-4-6` or `sonnet-4.6` patterns

### Scenario 2: Capability lookup
**Given** the model ID `claude-sonnet-4-6` is used
**When** capabilities are looked up in `MODEL_CAPABILITIES`
**Then** it returns `codeQuality: 'excellent'`, `contextWindow: 200000`, `costTier: 'standard'`

### Scenario 3: Model selection list
**Given** a user runs model setup or provider discovery
**When** the Anthropic provider model list is displayed
**Then** Claude Sonnet 4.6 appears as an option

## Technical Notes
- **Files to change**:
  - `scripts/flow-model-adapter.js` - Add patterns to MODEL_PATTERNS['claude-sonnet']
  - `scripts/flow-providers.js` - Add MODEL_CAPABILITIES entry + model list entry

## Dependencies
- None

## Complexity
Low - Adding entries to existing data structures
