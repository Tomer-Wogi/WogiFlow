# [wf-49394857] Enhanced wogi-review with project standards compliance and solution optimization agents

## User Story
**As a** developer using WogiFlow
**I want** /wogi-review to enforce project standards and suggest better solutions
**So that** all code follows the same conventions and quality improves over time

## Description
Enhance the existing /wogi-review command with two new agents:
1. **Agent 4: Standards Compliance** - Verifies code follows decisions.md, app-map.md, function-map.md, api-map.md, and .claude/rules/*
2. **Agent 5: Solution Optimization** - Suggests better technical approaches and UX improvements

Standards violations are STRICT - they block review completion until fixed. "All code must look like the same developer wrote it."

## Acceptance Criteria

### Scenario 1: Standards compliance agent catches violations
**Given** changed files that violate project standards
**When** I run /wogi-review
**Then** Agent 4 reports all violations with references to the violated rule
**And** the review is blocked until violations are fixed
**And** violations are categorized (decisions.md, app-map, function-map, api-map, naming-conventions)

### Scenario 2: Standards compliance agent passes clean code
**Given** changed files that follow all project standards
**When** I run /wogi-review
**Then** Agent 4 reports all checks passed
**And** the review continues to next phase

### Scenario 3: Solution optimization agent suggests improvements
**Given** code that works but could be improved
**When** I run /wogi-review
**Then** Agent 5 suggests technical alternatives (simpler libraries, better algorithms)
**And** Agent 5 suggests UX improvements (loading states, better error messages)
**And** suggestions are categorized by priority (High/Medium/Low)

### Scenario 4: Component duplication detection
**Given** I create a new component similar to an existing one in app-map.md
**When** I run /wogi-review
**Then** Agent 4 detects the duplication (>80% similarity)
**And** suggests using existing component or adding a variant
**And** blocks the review until addressed

### Scenario 5: Naming convention enforcement
**Given** I use `e` instead of `err` in a catch block
**When** I run /wogi-review
**Then** Agent 4 detects the naming-conventions.md violation
**And** reports the exact line number and required fix
