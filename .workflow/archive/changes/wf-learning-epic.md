# [Epic] Interactive Learning Commands — /wogi-decide, /wogi-learn, /wogi-retrospective

## Summary
Add 3 new structured workflows that close the gap between passive learning (auto-promotion at count >= 3) and user-initiated rule creation. Currently, when a user says "from now on, always do X", there's no workflow — it falls through as exploration or gets misrouted to /wogi-story.

## Stories
1. **wf-decide** — `/wogi-decide`: Interactive rule creation with clarifying questions
2. **wf-learn** — `/wogi-learn`: Pattern promotion from feedback-patterns to decisions
3. **wf-retro** — `/wogi-retrospective`: Session learning extraction and capture
4. **wf-route-learn** — Update `/wogi-start` routing to detect learning/rule intents
