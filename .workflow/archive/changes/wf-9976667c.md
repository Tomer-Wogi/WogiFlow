## User Story

As a team lead, I want to see which team members are currently active and what they're working on, so I can coordinate work and avoid conflicts.

## Description

This story adds team presence tracking via periodic heartbeats. Each active WogiFlow session reports its status (active, idle, task in progress) to the server. The presence API returns who's online, what task they're working on, and when they were last seen. Uses simple HTTP polling (not WebSocket) for MVP — WebSocket upgrade is deferred.

## Acceptance Criteria

### AC1: Presence heartbeat
Given an active Claude Code session with Teams enabled
When 5 minutes pass
Then a heartbeat is sent to POST `/api/sync/:projectId/presence`
With: userId, status ('active'/'idle'), currentTaskId, sessionStartedAt

### AC2: Presence query
Given 3 team members with active sessions
When GET `/api/sync/:projectId/presence` is called
Then all 3 members are returned with their status, task, and lastSeenAt
And members not seen in 15 minutes are marked 'offline'

### AC3: Session start/end presence
Given a team member starting a session
When session-start hook fires
Then presence is set to 'active'
And when session-end fires, presence is set to 'offline'

### AC4: Task context in presence
Given member A is working on task wf-001
When presence is queried
Then member A's entry shows currentTaskId: 'wf-001' and taskTitle

### AC5: Stale presence cleanup
Given a member whose last heartbeat was 15+ minutes ago
When presence is queried
Then they appear as 'offline'
And their locks are eligible for expiry

### AC6: Team status summary
Given a project with presence data
When GET `/api/sync/:projectId/status` is called
Then it returns: onlineCount, activeTaskCount, unclaimedTaskCount, recentCompletions

## Technical Notes

### DB Addition to 004_sync.sql

```sql
CREATE TABLE team_presence (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id),
  status TEXT NOT NULL DEFAULT 'active',  -- 'active', 'idle', 'offline'
  current_task_id TEXT,
  session_started_at TIMESTAMPTZ,
  last_seen_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(project_id, user_id)
);

CREATE INDEX idx_presence_project ON team_presence(project_id);
CREATE INDEX idx_presence_last_seen ON team_presence(last_seen_at);
```

### API Endpoints

| Method | Path | Description |
|--------|------|-------------|

| GET | `/api/sync/:projectId/presence` | Get team presence |
| GET | `/api/sync/:projectId/status` | Team status summary |
