# Extend Routing Gate Hook to Block Read/Glob/Grep Before wogi-* Routing

**ID**: wf-19b06f22
**Type**: fix
**Priority**: P0
**Feature**: workflow

## User Story

As a WogiFlow user, I want the routing gate to block Read/Glob/Grep tools (not just Bash) before a `/wogi-*` command has been invoked, so that ALL codebase interactions are tracked through the workflow.

## Description

The routing gate currently only blocks `Bash` and `EnterPlanMode` before a `/wogi-*` command is invoked. However, Read/Glob/Grep tools bypass the gate entirely because:
1. The PreToolUse hook matcher (`Edit|Write|TodoWrite|Skill|Bash`) doesn't include Read/Glob/Grep
2. Even if the hook fired, `GATED_TOOLS` only contains `Bash` and `EnterPlanMode`
3. Additionally, `EnterPlanMode` is in GATED_TOOLS but NOT in the PreToolUse matcher (dead letter)

This allows Claude to start reading/searching the codebase without routing through a `/wogi-*` command first.

## Acceptance Criteria

### Scenario 1: PreToolUse matcher includes Read/Glob/Grep/EnterPlanMode
Given the hook registration in `settings.local.json`
When the PreToolUse matcher regex is evaluated
Then it matches Read, Glob, Grep, and EnterPlanMode in addition to existing tools

### Scenario 2: GATED_TOOLS includes Read/Glob/Grep
Given the routing gate core logic in `routing-gate.js`
When `checkRoutingGate()` is called with toolName 'Read', 'Glob', or 'Grep'
Then the tool is recognized as a gated tool and routing check is performed

### Scenario 3: Pre-tool-use entry checks routing gate for Read/Glob/Grep
Given the entry hook in `pre-tool-use.js`
When a Read, Glob, or Grep tool call arrives before any `/wogi-*` routing
Then the routing gate blocks it with a descriptive message

### Scenario 4: EnterPlanMode is in both matcher and GATED_TOOLS
Given EnterPlanMode was already in GATED_TOOLS but not in the matcher
When the matcher is updated
Then EnterPlanMode is properly gated end-to-end

## Technical Notes

### Files to Change
1. `.claude/settings.local.json` — Update PreToolUse matcher regex
2. `scripts/hooks/core/routing-gate.js` — Add Read/Glob/Grep to GATED_TOOLS, update block message
3. `scripts/hooks/entry/claude-code/pre-tool-use.js` — Extend routing gate condition

### Boundaries
- Do NOT modify the routing gate logic for Bash (already working)
- Do NOT change how the `.routing-pending` flag is set/cleared
- Do NOT modify UserPromptSubmit or PostToolUse hooks
