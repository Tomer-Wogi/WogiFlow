# Config Consolidation - Merge Duplicate Sections

**ID**: wf-1d612670
**Epic**: wf-ea2c59c1 (WogiFlow Deep Optimization)
**Type**: refactor | **Level**: L1 | **Priority**: P1

## Problem

config.json has 108 top-level keys, 47KB, ~12K tokens loaded every session. Many sections are duplicates or only work when enabled together.

## Acceptance Criteria

1. **Given** tasks and loops sections exist with duplicate keys, **When** config is consolidated, **Then** a single `execution` section replaces both with no duplicated keys
2. **Given** memory has 5 scattered flags, **When** consolidated, **Then** single `memory.level` (off/minimal/standard/full) controls all memory behavior
3. **Given** learning has 6 sections (sessionLearning, crossSessionLearning, learning, automaticPromotion, knowledgeRouting, modelAdapters), **When** consolidated, **Then** single `learning` section with level control
4. **Given** context has 7 overlapping sections, **When** consolidated, **Then** single `context` section (smartCompaction + proactiveCompaction stay as infrastructure sub-keys)
5. **Given** review has 4 sections (review, reviewFix, peerReview, triage), **When** consolidated, **Then** single `review` section
6. **Given** multi-model has 4 overlapping sections (hybrid, multiModel, cascade, models), **When** consolidated, **Then** single `models` section
7. **Given** research + planMode overlap, **When** consolidated, **Then** single `research` section
8. **Given** parallel + bulkOrchestrator + taskQueue overlap, **When** consolidated, **Then** single `parallelExecution` section
9. **Given** old registry keys exist alongside registries[], **When** consolidated, **Then** old keys removed, registries[] is sole config
10. **Given** community + communitySync duplicate, **When** consolidated, **Then** single `community` section
11. **Given** workflowSteps has 11 all-disabled sub-sections (100 lines), **When** consolidated, **Then** compressed to enabled list with defaults in code
12. **Given** hooks.rules has 15 individual flags, **When** consolidated, **Then** grouped by concern (enforcement/intelligence/lifecycle)

## Files to Change

- `.workflow/config.json` — primary target
- `scripts/flow-utils.js` — getConfig() may need compat layer
- `config.schema.json` — schema update

## Boundary Declarations

- Do NOT change any runtime behavior — purely structural consolidation
- Do NOT remove any config capability — every current setting must remain accessible
- Consumer script updates are in Story 3 (wf-67eee59b), not this story
