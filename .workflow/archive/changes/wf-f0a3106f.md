# Story: Remove dead multi-CLI support code and false claims

**ID**: wf-f0a3106f
**Type**: refactor
**Priority**: P1
**Feature**: cleanup
**Created**: 2026-02-19

## User Story

As a project maintainer, I want all dead multi-CLI code removed so that the codebase accurately reflects what is actually supported (Claude Code only) and doesn't mislead users or contributors.

## Description

WogiFlow's README and code claim support for 6 AI coding CLIs (Claude Code, Gemini CLI, Cursor, OpenCode, Codex, Kimi) but only Claude Code is actually implemented. Dead templates, stale generated files, false documentation claims, and unused constants create confusion and undermine credibility. This was identified by an external Codex review.

## Acceptance Criteria

### AC1: README accurately describes supported CLIs
**Given** the README.md file
**When** a user reads it
**Then** it only claims Claude Code support, the "Supported CLIs" table is removed or replaced with Claude Code only, and the "Switching CLIs" section is removed

### AC2: Stale generated files removed
**Given** the generated files GEMINI.md and AGENTS.md
**When** they are not functionally maintained or used
**Then** they are deleted from the repository

### AC3: Dead template removed
**Given** `.workflow/templates/agents-md.hbs` (old Codex template)
**When** no bridge invokes it
**Then** it is deleted

### AC4: Dead code in scripts cleaned up
**Given** scripts with multi-CLI references
**When** those references serve no functional purpose
**Then** they are removed:
- `scripts/flow-utils.js`: Remove dead env var checks in `getSessionId()` for GEMINI/CODEX/OPENCODE
- `scripts/hooks/core/constants.js`: Remove OpenCode/Codex tool names from WRITE_TOOLS
- `scripts/flow-hooks.js`: Fix help text that claims multi-CLI support

### AC5: Config schema cleaned up
**Given** `.workflow/config.schema.json` with empty `gemini` and `codex` placeholders
**When** these are marked "(future)" with no properties
**Then** they are removed

### AC6: Bridge architecture comments corrected
**Given** `.workflow/bridges/base-bridge.js` comments mentioning "Gemini CLI, etc."
**When** only Claude Code bridge exists
**Then** comments are updated to reflect reality

### AC7: Roadmap items updated
**Given** roadmap phases 0.1.3-0.1.5 and 0.1.10 for multi-CLI support
**When** they were deferred since January and never started
**Then** they are marked as "Cancelled" with a note explaining why
