# [wf-4c237257-16] E4-S2: Content Type Classification

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 4: Auto-trigger & Formats**

## User Story
**As a** user with a large input
**I want** Claude to intelligently determine if it needs digestion
**So that** code dumps and documentation aren't unnecessarily processed

## Description
Implement classification logic that determines if large input is requirements/specs (needs digestion) or other content (doesn't need digestion).

## Acceptance Criteria

### Scenario 1: Requirements detected
**Given** large input contains phrases like "we need", "should have", "must support", "add a feature for"
**When** classification runs
**Then** content is classified as "requirements"
**And** digestion is auto-triggered

### Scenario 2: Transcript detected
**Given** large input has transcript markers (timestamps, speaker labels, conversational flow)
**When** classification runs
**Then** content is classified as "transcript"
**And** digestion is auto-triggered

### Scenario 3: Code detected
**Given** large input is primarily code (>70% code blocks or syntax patterns)
**When** classification runs
**Then** content is classified as "code"
**And** digestion is NOT triggered
**And** normal processing continues

### Scenario 4: Documentation detected
**Given** large input is primarily documentation/explanation (no actionable requirements)
**When** classification runs
**Then** content is classified as "documentation"
**And** user is asked if they want to extract action items

### Scenario 5: Ambiguous content
**Given** content type is unclear
**When** classification runs
**Then** user is asked: "This looks like a large input. Should I run the digestion process to ensure nothing is missed?"
**And** user can approve or decline

### Scenario 6: Risk assessment
**Given** any large input
**When** assessing risk of missing items
**Then** if risk is detected (even small), prefer triggering digestion
**And** bias toward safety over efficiency

## Technical Notes
- **Classification signals**: Keyword patterns, structure analysis, code detection
- **Risk factors**: Multiple topics, requirement keywords, conversational markers
- **Output**: Classification + confidence + recommendation

## Dependencies
