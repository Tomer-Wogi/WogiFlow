# [wf-4c237257-21] E5-S3: Session Persistence (Durable Digest)

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 5: Multi-language & Persistence**

## User Story
**As a** user who may need to pause during digestion
**I want** complete session persistence
**So that** I can resume exactly where I left off

## Description
Implement full session persistence for the digestion workflow, integrating with wogi-flow's existing durable sessions feature to allow resume after any interruption.

## Acceptance Criteria

### Scenario 1: State saved continuously
**Given** digestion is in progress
**When** any state changes (topic extracted, question answered, story approved)
**Then** state is immediately persisted
**And** crash-safe (no data loss on unexpected termination)

### Scenario 2: Resume detection
**Given** user starts a new session
**When** active-digest.json indicates incomplete session
**Then** user is prompted: "You have an unfinished digestion session. Resume?"
**And** user can resume or start fresh

### Scenario 3: Full context recovery
**Given** user resumes a session
**When** context is loaded
**Then** all extracted topics are restored
**And** all statements and mappings are restored
**And** all clarification Q&A is restored
**And** approval progress is restored

### Scenario 4: Resume mid-clarification
**Given** session was interrupted during clarification
**When** resumed
**Then** answered questions are not re-asked
**And** pending questions are presented
**And** flow continues naturally

### Scenario 5: Resume mid-approval
**Given** session was interrupted during story approval
**When** resumed
**Then** approved stories are already in ready.json
**And** current story is re-presented
**And** remaining stories are shown in order

### Scenario 6: /wogi-resume integration
**Given** user runs /wogi-resume
**When** there's an active digest session
**Then** digest session is detected and resumed
**And** integrates with existing wogi-flow durable sessions

## Technical Notes
- **State files**: `active-digest.json` + full session folder
- **Integration**: Works with existing `/wogi-resume` command
- **Recovery**: Full context reconstruction from state files

## Dependencies
- [wf-4c237257-01] State structure must exist
- Existing wogi-flow durable sessions feature

## Scope
**M** - Session persistence and recovery
