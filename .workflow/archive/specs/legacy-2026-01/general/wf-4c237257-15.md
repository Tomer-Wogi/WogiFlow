# [wf-4c237257-15] E4-S1: Large Input Detection

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 4: Auto-trigger & Formats**

## User Story
**As a** user who pastes a large input
**I want** Claude to automatically detect it needs digestion
**So that** I don't accidentally send large requests without proper processing

## Description
Implement detection logic that identifies when user input exceeds the threshold for reliable processing and should trigger the digestion workflow.

## Acceptance Criteria

### Scenario 1: Threshold detection
**Given** user pastes text > 2000 words (configurable)
**When** the input is received
**Then** large input is detected
**And** content type classification is triggered

### Scenario 2: Word count calculation
**Given** any user input
**When** checking size
**Then** word count is calculated accurately
**And** excludes code blocks if configured
**And** threshold is checked against config value

### Scenario 3: Below threshold
**Given** user input < threshold
**When** checking size
**Then** normal processing continues
**And** no digestion is triggered

### Scenario 4: Threshold configuration
**Given** config has `autoTriggerThreshold: 2000`
**When** threshold is checked
**Then** the configured value is used
**And** default is 2000 if not configured

### Scenario 5: Size indicator
**Given** large input is detected
**When** proceeding with digestion
**Then** user is informed: "Processing large input (~3500 words)..."
**And** progress is indicated during extraction

## Technical Notes
- **Threshold**: Configurable in `config.json → transcriptDigestion.autoTriggerThreshold`
- **Calculation**: Word count, excluding markdown code blocks optionally
- **Output**: Boolean decision + word count

## Dependencies
- [wf-4c237257-01] Config section must exist

## Scope
**S** - Size detection logic
