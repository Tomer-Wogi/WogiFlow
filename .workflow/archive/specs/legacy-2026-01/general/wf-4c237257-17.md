# [wf-4c237257-17] E4-S3: VTT/SRT Format Parsing

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 4: Auto-trigger & Formats**

## User Story
**As a** user with transcripts from video meetings
**I want** to import VTT and SRT caption files
**So that** I can use existing transcriptions from Zoom, Teams, etc.

## Description
Implement parsers for VTT (Web Video Text Tracks) and SRT (SubRip Subtitle) formats commonly exported from video conferencing tools.

## Acceptance Criteria

### Scenario 1: VTT format parsed
**Given** a .vtt file or VTT-formatted text
**When** parsing
**Then** timestamps are extracted
**And** speaker labels are identified (if present)
**And** text content is extracted cleanly

### Scenario 2: SRT format parsed
**Given** a .srt file or SRT-formatted text
**When** parsing
**Then** sequence numbers are handled
**And** timestamps are extracted
**And** text content is extracted cleanly

### Scenario 3: Timestamp preservation
**Given** a parsed transcript
**When** statements are extracted
**Then** original timestamps are preserved
**And** can be referenced in source tracing

### Scenario 4: Speaker identification
**Given** transcript with speaker labels (e.g., "Speaker 1:", "[John]:")
**When** parsing
**Then** speakers are identified
**And** statements are attributed to speakers
**And** speaker names are normalized

### Scenario 5: Auto-format detection
**Given** pasted text that looks like VTT or SRT
**When** input is received
**Then** format is auto-detected
**And** appropriate parser is used

### Scenario 6: Malformed input handling
**Given** partially corrupted VTT/SRT
**When** parsing
**Then** recoverable content is extracted
**And** errors are logged but don't block processing
**And** user is warned of potential gaps

## Technical Notes
- **VTT format**: WEBVTT header, timestamp lines, cue text
- **SRT format**: Sequence number, timestamp line, subtitle text
- **Output**: Normalized transcript with timestamps and speakers

## Dependencies
- [wf-4c237257-16] Content classification must recognize these formats

## Scope
**M** - VTT and SRT parser implementation
