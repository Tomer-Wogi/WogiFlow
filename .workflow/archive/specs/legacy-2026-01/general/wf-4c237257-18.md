# [wf-4c237257-18] E4-S4: Zoom/Teams Export Parsing

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 4: Auto-trigger & Formats**

## User Story
**As a** user with transcripts from video conferencing tools
**I want** to import native export formats from Zoom, Teams, and Meet
**So that** I can use transcripts without manual conversion

## Description
Implement parsers for common video conferencing transcript export formats, handling their specific structures and metadata.

## Acceptance Criteria

### Scenario 1: Zoom transcript parsed
**Given** a Zoom transcript export (TXT or VTT)
**When** parsing
**Then** Zoom-specific formatting is handled
**And** speaker names are extracted
**And** timestamps are normalized

### Scenario 2: Teams transcript parsed
**Given** a Microsoft Teams transcript export
**When** parsing
**Then** Teams-specific formatting is handled
**And** speaker identification works
**And** timestamps are extracted

### Scenario 3: Google Meet parsed
**Given** a Google Meet transcript
**When** parsing
**Then** Meet-specific formatting is handled
**And** content is extracted cleanly

### Scenario 4: Otter.ai parsed
**Given** an Otter.ai transcript export
**When** parsing
**Then** Otter formatting is handled
**And** speaker labels and timestamps work

### Scenario 5: Format auto-detection
**Given** pasted meeting transcript
**When** input is received
**Then** source platform is auto-detected if possible
**And** appropriate parser is used

### Scenario 6: Unknown format fallback
**Given** transcript from unknown source
**When** parsing
**Then** generic transcript parsing is used
**And** best-effort extraction is performed
**And** user is warned about potential formatting issues

## Technical Notes
- **Zoom**: TXT with timestamps, VTT, or JSON export
- **Teams**: DOCX or TXT with specific formatting
- **Meet**: SRT or TXT export
- **Otter**: TXT with speaker labels and timestamps
- **Output**: Normalized transcript format

## Dependencies
- [wf-4c237257-17] VTT/SRT parsers as foundation

## Scope
**M** - Multiple format parsers
