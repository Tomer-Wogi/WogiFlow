# [wf-4c237257-19] E5-S1: Language Detection

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 5: Multi-language & Persistence**

## User Story
**As a** user with non-English transcripts
**I want** Claude to detect the language automatically
**So that** processing works without manual language specification

## Description
Implement automatic language detection for transcripts, supporting English, Ukrainian, Russian, and Hebrew.

## Acceptance Criteria

### Scenario 1: English detection
**Given** a transcript in English
**When** language detection runs
**Then** language is identified as "en"
**And** confidence score is provided

### Scenario 2: Ukrainian detection
**Given** a transcript in Ukrainian
**When** language detection runs
**Then** language is identified as "uk"
**And** Cyrillic characters are handled correctly

### Scenario 3: Russian detection
**Given** a transcript in Russian
**When** language detection runs
**Then** language is identified as "ru"
**And** distinguished from Ukrainian

### Scenario 4: Hebrew detection
**Given** a transcript in Hebrew
**When** language detection runs
**Then** language is identified as "he"
**And** RTL text is handled correctly

### Scenario 5: Mixed language handling
**Given** a transcript with mixed languages (e.g., English with Ukrainian words)
**When** language detection runs
**Then** primary language is identified
**And** secondary language is noted
**And** processing continues with primary

### Scenario 6: Unknown language fallback
**Given** a transcript in unsupported language
**When** language detection runs
**Then** it's flagged as unsupported
**And** user is asked to confirm language
**And** English processing is used as fallback

## Technical Notes
- **Detection method**: Character analysis, common word patterns
- **Supported**: en, uk, ru, he (extensible)
- **Output**: Language code + confidence

## Dependencies
- [wf-4c237257-01] Skill structure for config
