# [wf-4c237257-07] E2-S2: Clarification Conversation Loop

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 2: Clarification System**

## User Story
**As a** user answering clarification questions
**I want** a natural conversational flow
**So that** I can provide answers without friction

## Description
Implement the conversation loop that presents questions, captures answers, and generates follow-up questions until all specs are complete. No slash commands required.

## Acceptance Criteria

### Scenario 1: Question presentation
**Given** clarification questions exist for a topic
**When** presenting to user
**Then** questions are shown in a readable format
**And** user can answer in natural language (voice or text)

### Scenario 2: Answer capture
**Given** user provides an answer like "yes, add name, email, and role columns"
**When** the answer is processed
**Then** the answer is linked to the original question
**And** the statement-map is updated with the new detail
**And** the question is marked as answered

### Scenario 3: Follow-up generation
**Given** an answer that raises new questions
**When** the answer is processed
**Then** follow-up questions are generated if needed
**And** the loop continues until complete

### Scenario 4: Partial answers
**Given** user answers some questions but not others
**When** processing the response
**Then** answered questions are marked complete
**And** unanswered questions are re-presented

### Scenario 5: Completion detection
**Given** all questions for all topics are answered
**When** checking completion status
**Then** clarification phase is marked complete
**And** flow proceeds to story generation

## Technical Notes
- **Conversation state**: Track which questions are answered
- **Natural language parsing**: Extract answers from user's response
- **Output**: Updated `clarifications.json` with answers

## Dependencies
- [wf-4c237257-06] Question generation must exist

## Scope
**M** - Conversation loop logic
