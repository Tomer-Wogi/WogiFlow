# [wf-4c237257-20] E5-S2: Multi-language Clarification

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 5: Multi-language & Persistence**

## User Story
**As a** user with a non-English transcript
**I want** clarification questions in my language
**So that** I can respond naturally without translation

## Description
Implement multi-language support for the clarification conversation, asking questions and understanding answers in the detected language.

## Acceptance Criteria

### Scenario 1: Questions in detected language
**Given** a Ukrainian transcript
**When** clarification questions are generated
**Then** questions are asked in Ukrainian
**And** examples are in Ukrainian

### Scenario 2: Russian clarification
**Given** a Russian transcript
**When** clarification runs
**Then** conversation is in Russian
**And** technical terms may remain in English if standard

### Scenario 3: Hebrew clarification
**Given** a Hebrew transcript
**When** clarification runs
**Then** conversation is in Hebrew
**And** RTL formatting is appropriate

### Scenario 4: Answers in any language
**Given** clarification is in Ukrainian
**When** user answers in Russian or English
**Then** the answer is understood
**And** processing continues correctly

### Scenario 5: Output language preference
**Given** non-English transcript processed
**When** stories are generated
**Then** stories are in English by default
**And** user can configure output language preference
**And** technical terms are in English

### Scenario 6: Source preservation
**Given** non-English transcript
**When** source statements are traced
**Then** original language text is preserved
**And** translation is provided if needed

## Technical Notes
- **Clarification language**: Match transcript language
- **Story output**: Configurable (default English)
- **Term handling**: Technical terms may remain English

## Dependencies
- [wf-4c237257-19] Language detection must work

## Scope
**M** - Multi-language conversation logic
