# [wf-4c237257-02] E1-S2: Pass 1 - Topic Extraction

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 1: Core Extraction Engine**

## User Story
**As a** user providing a transcript
**I want** Claude to identify all distinct topics/features discussed
**So that** requirements can be organized by theme without mixing contexts

## Description
Implement the first pass of the multi-pass extraction algorithm. This pass reads the entire transcript and identifies distinct topics (features, fixes, improvements, etc.). Each topic is assigned an ID, title, and the position where it was first mentioned.

## Acceptance Criteria

### Scenario 1: Topics identified from clear discussion
**Given** a transcript discussing "user dashboard" and "analytics integration"
**When** Pass 1 runs
**Then** two topics are created with unique IDs
**And** each topic has a title derived from the discussion
**And** first mention position is recorded for each

### Scenario 2: Topics identified from mixed discussion
**Given** a transcript that jumps between topics (discusses A, then B, then back to A)
**When** Pass 1 runs
**Then** topics are correctly identified as distinct (not duplicated)
**And** each topic captures all its mentions (even non-contiguous)

### Scenario 3: Subtle topic separation
**Given** a transcript where topics are related but distinct (e.g., "login form" vs "password reset")
**When** Pass 1 runs
**Then** related but distinct topics are separated
**And** not incorrectly merged into one topic

### Scenario 4: Confidence scoring
**Given** a topic extraction
**When** the topic is saved
**Then** a confidence score (0-1) is assigned
**And** low-confidence topics are flagged for verification

### Scenario 5: Output format
**Given** Pass 1 completes
**When** topics.json is written
**Then** each topic has: `id`, `title`, `description`, `firstMentionPosition`, `confidence`
**And** topics are ordered by first mention position

## Technical Notes
- **Algorithm approach**: Semantic chunking, topic shift detection, related statement clustering
- **Output**: `topics.json` with topic objects
