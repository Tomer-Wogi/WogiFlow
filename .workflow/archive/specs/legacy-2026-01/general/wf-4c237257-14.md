# [wf-4c237257-14] E3-S5: ready.json Integration

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 3: Story Generation & Approval**

## User Story
**As a** user who approved stories
**I want** them automatically added to ready.json
**So that** I can start working on them immediately

## Description
Implement the integration that adds approved stories to ready.json using the existing wogi-flow task structure, maintaining proper hierarchy (parent/sub-tasks) and dependencies.

## Acceptance Criteria

### Scenario 1: Story added on approval
**Given** I approve a story
**When** the approval is processed
**Then** the story is added to ready.json immediately
**And** the story file is created in `.workflow/changes/`
**And** status is "ready"

### Scenario 2: Parent-child structure
**Given** stories are organized into epics
**When** adding to ready.json
**Then** parent tasks are created for epics
**And** stories are sub-tasks with parent reference
**And** hierarchy is preserved

### Scenario 3: Dependencies maintained
**Given** Story B depends on Story A
**When** both are added to ready.json
**Then** Story B has dependency on Story A
**And** dependency order matches transcript flow

### Scenario 4: Silent operation
**Given** I approve a story
**When** it's added to ready.json
**Then** no confirmation message is shown (just proceeds to next)
**And** running total is shown: "4 of 12 approved"

### Scenario 5: Post-approval prompt
**Given** all stories are approved
**When** the flow completes
**Then** I see: "All 12 stories added to ready.json"
**And** summary by epic/phase is shown
**And** I'm asked: "Want me to start developing?"

### Scenario 6: Partial approval handling
**Given** some stories are skipped (not approved or rejected)
**When** the session ends
**Then** pending stories remain in digest state
**And** user can resume and approve later

## Technical Notes
- **Integration**: Use existing ready.json structure
- **File creation**: Standard wogi story format
- **Dependencies**: Extract from topic flow and user clarification
