# [wf-4c237257] Transcript Digestion - Multi-pass extraction system for large inputs

## User Story
**As a** developer or product owner
**I want** to feed large transcripts/specs to Claude and have every requirement extracted methodically
**So that** nothing is missed, no assumptions are made, and I get complete stories with full acceptance criteria

## Description
Long transcripts (1-2 hours) from team calls contain rich requirements, but LLMs typically miss details, have recency bias (later discussion overshadows earlier points), and confuse context across features. This feature implements a multi-pass extraction system that tracks every statement, asks clarifying questions, generates stories with source traceability, and presents them one-by-one for approval. It also auto-triggers on large inputs to prevent the user from accidentally sending unprocessed large requests.

## Acceptance Criteria

### Scenario 1: Process transcript successfully
**Given** I provide a 1-hour call transcript (voice recording, paste, or file)
**When** Claude processes it
**Then** Claude identifies all distinct topics/features
**And** maps every meaningful statement to a topic
**And** detects any contradictions (mind-changes during the call)
**And** asks me clarifying questions until specs are complete

### Scenario 2: Statement-level verification
**Given** Claude has extracted all topics and clarified requirements
**When** the verification phase runs
**Then** every statement in the original transcript is mapped to a story
**And** coverage shows 100% (no orphan statements)
**And** any gaps are flagged for resolution

### Scenario 3: One-by-one story approval
**Given** Claude has generated stories from the transcript
**When** presenting stories for approval
**Then** I see one story at a time with full acceptance criteria
**And** I can say "Approve" to add it to ready.json
**And** I can say "Change X to Y" to modify before approving
**And** I can say "Show all remaining" to see the full list
**And** no slash commands are required from me

### Scenario 4: Contradiction handling
**Given** I changed my mind during the transcript ("actually, no, let's do X instead")
**When** Claude detects the contradiction
**Then** obvious corrections are auto-resolved (using the latest)
**And** ambiguous contradictions are flagged for me to clarify

### Scenario 5: Auto-trigger on large input
**Given** I paste a large input (>2000 words) that looks like requirements/specs
**When** Claude detects the risk of missing things
**Then** Claude automatically starts the digestion process
**And** does not ask for permission (if clearly requirements)
**And** asks first only if input type is ambiguous

### Scenario 6: Multi-language support
**Given** I provide a transcript in Ukrainian, Russian, or Hebrew
**When** Claude processes it
**Then** language is auto-detected
**And** clarification questions are asked in that language
**And** stories are generated in English (or user's preferred language)

### Scenario 7: Session persistence
**Given** I close the chat mid-digestion
**When** I return and run /wogi-resume
**Then** the digestion state is restored
**And** I continue from where I left off (topics, statements, pending approvals)
