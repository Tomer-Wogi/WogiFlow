# [wf-4c237257-12] E3-S3: One-by-One Presentation Flow

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 3: Story Generation & Approval**

## User Story
**As a** user reviewing generated stories
**I want** to see them one at a time
**So that** I can focus on each story and provide feedback without overwhelm

## Description
Implement the presentation flow that shows stories one-by-one, with options to navigate, approve, request changes, or see all remaining stories.

## Acceptance Criteria

### Scenario 1: Single story presentation
**Given** 12 stories have been generated
**When** starting the approval flow
**Then** I see: "Here's Story 1 of 12: [Title]"
**And** full story content is shown (user story, acceptance criteria, sources)
**And** I'm asked: "Approve, or what should I change?"

### Scenario 2: Navigation options
**Given** a story is presented
**When** I can respond with:
**Then** "Approve" / "Yes" / "Good" → approves and shows next
**And** "Show next" → skips to next (marks current as pending)
**And** "Show all remaining" → lists all pending stories
**And** "Go back" → shows previous story

### Scenario 3: Progress tracking
**Given** I'm reviewing story 5 of 12
**When** viewing the presentation
**Then** I see progress: "Story 5 of 12 | 4 approved, 0 pending changes"

### Scenario 4: Grouped view option
**Given** I say "Show all remaining"
**When** the list is displayed
**Then** stories are grouped by epic/phase
**And** I can select any story to view in detail

### Scenario 5: Natural language control
**Given** any point in the flow
**When** I say things like "let's see the next one" or "go back to the dashboard story"
**Then** the intent is understood
**And** no slash commands needed

## Technical Notes
- **State tracking**: Current position, approval status per story
- **Natural language parsing**: Understand navigation intents
- **Output**: Presentation state in digest session

## Dependencies
- [wf-4c237257-11] Story template with sources must exist

## Scope
**M** - Presentation and navigation logic
