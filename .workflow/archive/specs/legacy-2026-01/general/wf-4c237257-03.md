# [wf-4c237257-03] E1-S3: Pass 2 - Statement Association

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 1: Core Extraction Engine**

## User Story
**As a** user who provided a transcript
**I want** every meaningful statement mapped to its topic
**So that** no requirement is lost or misattributed

## Description
Implement the second pass that goes through every statement in the transcript and associates it with a topic from Pass 1. This is the core of the "nothing missed" guarantee.

## Acceptance Criteria

### Scenario 1: Direct statement mapping
**Given** a statement "the table should have a delete action per row"
**And** a topic "User Dashboard" exists
**When** Pass 2 processes this statement
**Then** the statement is mapped to "User Dashboard"
**And** the mapping includes position and confidence

### Scenario 2: Filler/greeting exclusion
**Given** statements like "okay", "um", "hi everyone", "let's get started"
**When** Pass 2 processes these
**Then** they are marked as non-meaningful
**And** not mapped to any topic

### Scenario 3: Ambiguous statement handling
**Given** a statement that could belong to multiple topics
**When** Pass 2 processes it
**Then** it's assigned to the most likely topic based on context
**And** confidence score reflects the ambiguity
**And** if confidence < 0.7, it's flagged for clarification

### Scenario 4: Orphan detection
**Given** a meaningful statement that doesn't fit any existing topic
**When** Pass 2 processes it
**Then** it's marked as orphan (topic_id = null)
**And** added to orphans list for Pass 3

### Scenario 5: Contradiction detection
**Given** two statements that contradict each other
**When** Pass 2 processes both
**Then** the later statement has `contradicts` pointing to earlier
**And** both are still mapped (resolution happens in Pass 4)

## Technical Notes
- **Statement splitting**: Semantic units, not just sentences
- **Context awareness**: Use surrounding statements to determine topic
- **Confidence threshold**: 0.7 for automatic mapping
- **Output**: `statement-map.json`

## Dependencies
- [wf-4c237257-02] Topics must be extracted first

## Scope
**L** - Core algorithm with many edge cases
