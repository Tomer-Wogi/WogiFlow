# [wf-4c237257-06] E2-S1: Question Generation Logic

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 2: Clarification System**

## User Story
**As a** user with incomplete requirements in my transcript
**I want** Claude to ask smart clarifying questions
**So that** specs are complete before story generation

## Description
Implement the logic that generates clarifying questions for each topic based on what's missing or unclear. Questions should be specific, actionable, and grouped by topic.

## Acceptance Criteria

### Scenario 1: Completeness questions
**Given** a topic "User Dashboard" with statement "add a table with user data"
**When** question generation runs
**Then** questions are generated: "Which columns should the table display?" "Should columns be sortable?" "Any row actions needed?"

### Scenario 2: Specificity questions
**Given** vague statements like "make it look nice" or "add some validation"
**When** question generation runs
**Then** specific questions are generated to make them concrete
**And** examples are provided where helpful

### Scenario 3: Ambiguity questions
**Given** low-confidence statement mappings or unresolved contradictions
**When** question generation runs
**Then** clarification questions are generated
**And** options are presented when applicable

### Scenario 4: No unnecessary questions
**Given** a complete, specific statement like "add a red 'Delete' button that shows a confirmation modal"
**When** question generation runs
**Then** no questions are generated for this statement
**And** it's marked as complete

### Scenario 5: Question grouping
**Given** multiple questions across topics
**When** questions are presented
**Then** they're grouped by topic
**And** each topic's questions are numbered

## Technical Notes
- **Question types**: Completeness, Specificity, Ambiguity
- **Smart detection**: Don't ask about things already specified
- **Output**: Questions added to `clarifications.json`
