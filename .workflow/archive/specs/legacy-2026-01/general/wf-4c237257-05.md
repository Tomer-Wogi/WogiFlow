# [wf-4c237257-05] E1-S5: Pass 4 - Contradiction Resolution

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 1: Core Extraction Engine**

## User Story
**As a** user who may have changed my mind during the call
**I want** contradictions to be detected and resolved smartly
**So that** the final specs reflect my actual intent

## Description
Implement the fourth pass that handles all detected contradictions from Pass 2. The goal is to resolve obvious corrections automatically while flagging ambiguous ones for user clarification.

## Acceptance Criteria

### Scenario 1: Explicit correction auto-resolved
**Given** statements: "Let's make it blue" followed by "Actually, no, let's make it green"
**When** Pass 4 processes the contradiction
**Then** it's automatically resolved to "green"
**And** the earlier statement is marked `superseded: true`
**And** no user clarification needed

### Scenario 2: Correction phrases detected
**Given** phrases like "actually", "no wait", "I changed my mind", "instead", "scratch that"
**When** Pass 4 scans for contradictions
**Then** these are recognized as correction indicators
**And** the statement following the phrase is used

### Scenario 3: Ambiguous contradiction flagged
**Given** statements: "The button should be on the left" and later "The button should be on the right"
**And** no explicit correction phrase
**When** Pass 4 processes this
**Then** it's flagged for user clarification
**And** both options are presented: "You mentioned both left and right placement - which do you prefer?"

### Scenario 4: Non-contradicting evolution
**Given** statements that seem contradictory but are actually additive
**When** Pass 4 analyzes them
**Then** they're recognized as not contradictory
**And** both are kept (e.g., "show 10 items" then "also allow 25 items" = pagination options)

### Scenario 5: Resolution output
**Given** Pass 4 completes
**When** results are saved
**Then** `statement-map.json` is updated with `superseded` flags
**And** `clarifications.json` includes pending contradiction questions
**And** count of auto-resolved vs needs-clarification is logged

## Technical Notes
- **Correction indicators**: "actually", "no", "wait", "instead", "scratch that", "forget that", "I meant", "let me rephrase"
- **Semantic contradiction detection**: Not just keyword matching - understand meaning
- **Output updates**:
  - `statement-map.json`: Add `superseded: true/false` and `superseded_by: "s-xxx"`
  - `clarifications.json`: Add contradiction questions to queue

## Dependencies
- [wf-4c237257-03] Contradictions must be detected in Pass 2

## Scope
**M** - Smart detection and resolution logic
