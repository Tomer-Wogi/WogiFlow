# [wf-4c237257-11] E3-S2: Story Template with Source Tracing

## Parent
Part of [wf-4c237257] Transcript Digestion Feature - **Epic 3: Story Generation & Approval**

## User Story
**As a** developer reading generated stories
**I want** to see which transcript statements each requirement came from
**So that** I can verify accuracy and understand context

## Description
Extend the story template to include a "Source Statements" section that traces each acceptance criterion back to the original transcript statements and clarification answers.

## Acceptance Criteria

### Scenario 1: Source statements included
**Given** a generated story
**When** viewing the story
**Then** a "Source Statements" section exists
**And** it lists the original transcript statements that led to this story

### Scenario 2: Acceptance criteria traced
**Given** an acceptance criterion like "table should be sortable"
**When** viewing the source
**Then** the originating statement is shown: "s-045: 'and we need sorting on the table'"
**And** position in transcript is indicated

### Scenario 3: Clarification answers traced
**Given** a requirement that came from clarification (not original transcript)
**When** viewing the source
**Then** the clarification Q&A is shown: "Q: Which columns? A: Name, Email, Role"
**And** it's distinguished from transcript sources

### Scenario 4: Multiple sources
**Given** a requirement informed by multiple statements
**When** viewing the source
**Then** all contributing statements are listed
**And** ordered by relevance/position

### Scenario 5: No made-up content
**Given** a generated story
**When** reviewing all content
**Then** every requirement traces to a source
**And** nothing is invented/assumed without source

## Technical Notes
- **Template extension**: Add `## Source Statements` section
- **Link format**: Statement ID + text excerpt + position
- **Clarification format**: Question + Answer + timestamp
