## Goal

Let an agent propose edits to IGR artifacts (`product.md`, `domain-model.md`, `user-journeys.md`, `glossary.md`) without directly mutating them. Proposals land in a staging directory; user approves or rejects at session-end. Prevents silent domain-model drift.

## Integration Point

- `scripts/flow-memory.js` — new CLI: `flow memory propose|approve|reject|list`.
- Agent invocation: agent runs `flow memory propose --block <name> --op <append|replace-section|replace-all> --content <file>`, OR emits `## MEMORY_PROPOSAL: <json>` blocks that a PostToolUse hook parses and stages.
- `scripts/hooks/core/session-end.js` — list pending proposals in session-end briefing.

No MCP tool registration. No `memory_propose` tool in any catalog.

## Acceptance Criteria

1. CLI: `flow memory propose --block <product|domain-model|user-journeys|glossary> --op <append|replace-section|replace-all> --content <file> [--rationale <text>]` stages proposal at `.workflow/state/memory-proposals/<id>.json`.
2. Operations: `append` (add to end), `replace-section` (replace by heading), `replace-all` (full rewrite — requires rationale).
3. Section-boundary safety: `replace-section` validates heading exists; malformed section → error, no state change.
4. CLI: `flow memory approve <id>` applies proposal to target artifact + archives proposal to `.workflow/state/memory-proposals/applied/`.
5. CLI: `flow memory reject <id> [--reason <text>]` moves to `.workflow/state/memory-proposals/rejected/`.
6. Session-end hook lists pending proposals with diff preview + approve/reject prompts.
7. Tests: propose round-trip (all 3 ops), approve round-trip, reject round-trip, section-boundary safety (3 malformed cases).
