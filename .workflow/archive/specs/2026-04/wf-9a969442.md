## Goal

`skill_manage(action="patch")` uses fuzzy find-replace so minor whitespace drift or reorderings don't break the patch. Pattern borrowed from Aider.

## Integration Point

Called from F1 `skill_manage` when action is `patch`.

## Acceptance Criteria

1. Fuzzy-match implementation: Levenshtein or similar, tolerates whitespace + line-ending drift
2. Patch applies atomically — rejects if match confidence below threshold (default 0.85)
3. Threshold configurable via `skills.fuzzyPatchThreshold`
4. Tests: exact match, whitespace-drift match, reordering-drift rejection, low-confidence rejection
