## Goal

Enable an agent to propose new/edited/removed skills during a session by writing structured records to a staging directory via the `flow skill` CLI. A session-end hook surfaces pending proposals for user batch approval. User-approval gate prevents arbitrary skill proliferation.

## Integration Point

- `scripts/flow-skill-manage.js` — new CLI: `flow skill propose|patch|remove|promote|archive`.
- `scripts/hooks/core/session-end.js` — list pending proposals in session-end briefing, prompt user to approve/reject.
- Agent invocation: agent runs the CLI via Bash, or emits a structured `## SKILL_PROPOSAL: <json>` block that a PostToolUse hook parses and stages.

No MCP tool registration. No `skill_manage` tool in any catalog.

## Acceptance Criteria

1. CLI: `flow skill propose --name <n> --content <file>` writes draft to `.claude/skills/pending/<name>.md` with metadata (proposer, timestamp, rationale).
2. CLI: `flow skill patch --name <n> --content <file>` stages an edit proposal (pairs with F3 fuzzy-match when that lands).
3. CLI: `flow skill remove --name <n>` soft-deletes to `.claude/skills/archived/<name>.md`.
4. CLI: `flow skill promote <name>` moves from `pending/` to active `.claude/skills/` (user-invoked only — not agent-callable).
5. Session-end hook lists pending proposals with summary + approve/reject prompts; writes user decisions back.
6. Tests: propose round-trip, promote round-trip, archive round-trip, session-end surfacing.
