## Goal

Replace the JSON message-bus in `lib/workspace-dispatch-tracking.js` with a SQLite-backed IPC using single-writer `inbound.db` + `outbound.db` per worker. Higher throughput, atomic reads, and crash-safe transactions. Highest-risk story in the epic.

## Integration Point

Drop-in replacement for the message-bus in workspace coordination. Manager writes to worker's `inbound.db`; worker writes to its `outbound.db`; manager reads from each worker's `outbound.db`.

## Acceptance Criteria

1. SQLite schema: `messages(id, kind, payload, created_at, consumed_at)` per DB
2. Single-writer contract enforced: manager writes inbound.db; worker writes outbound.db
3. Atomic read-and-mark-consumed transaction
4. Migration path: old JSON message-bus files detected + converted on first run
5. Backward-compat shim: if `sqlite3` npm module unavailable, fall back to JSON with deprecation warning
6. Multi-worker integration test: 3 workers dispatching concurrently, no message loss, no duplicates
7. Crash-safety test: kill worker mid-write, manager sees consistent state
