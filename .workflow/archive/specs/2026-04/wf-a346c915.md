# wf-a346c915 — A1 AGENTS.md alias for CLAUDE.md

**Type**: Story (L1)
**Parent**: wf-34290000 (extension-finalize epic, Workstream A)
**Status**: in-progress
**Priority**: P0
**Created**: 2026-04-23

## Goal

Ship WogiFlow projects with **both** `CLAUDE.md` and `AGENTS.md` (identical content). AGENTS.md is the emerging cross-tool standard used by Codex, Cline, Crush, Aider, and others. Generating both makes WogiFlow-enabled projects portable across CLI coding agents without forking their instruction file.

## Why

Research across 25 CLI coding agents showed a standardization trend toward `AGENTS.md` as the universal instructions file. WogiFlow currently generates only `CLAUDE.md`. If a user tries the same repo in another tool, that tool may not pick up the WogiFlow methodology. Generating AGENTS.md as an identical sibling — with CLAUDE.md still canonical for drift detection — removes the portability gap with zero cost to existing users.

## Design

**CLAUDE.md stays canonical.** AGENTS.md is a generated duplicate. Drift detection and the sync state hash continue to track CLAUDE.md only. The AGENTS.md file is regenerated on every sync; if a user manually edits AGENTS.md, their edits are overwritten on next sync — the canonical place for customization remains CLAUDE.md.

A new config flag `cli.generateAgentsMd` (default: `true`) gates the behavior. Setting it to `false` restores CLAUDE.md-only output.

## Acceptance criteria

1. **Bridge sync writes both**: `.workflow/bridges/base-bridge.js::generateRulesFile()` writes `CLAUDE.md` AND `AGENTS.md` with byte-identical content when `cli.generateAgentsMd !== false`.
2. **Installer writes both**: `lib/installer.js` simple-mode fallback (the path near line 783) also writes AGENTS.md alongside CLAUDE.md.
3. **Opt-out honored**: When `cli.generateAgentsMd === false`, only CLAUDE.md is written. No AGENTS.md created, no deletion of existing AGENTS.md (user may have their own).
4. **Drift detection unchanged**: `flow-bridge-state.js::checkClaudeMdDrift` continues to read `CLAUDE.md` only.
5. **Manual-modification protection preserved**: If AGENTS.md exists without the "Generated by CLI Bridge" marker, it is treated like a manually-maintained CLAUDE.md — skipped unless `--force`.
6. **Unit tests**: Cover (a) both files written, (b) opt-out via config, (c) manual-edit preservation for AGENTS.md without marker.
