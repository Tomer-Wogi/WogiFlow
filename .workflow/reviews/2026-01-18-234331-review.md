## Fixes Applied

### 1. Recursion Depth Limit (Critical)
Added `CASCADE_MAX_DEPTH = 10` constant and depth parameter to `cascadeCompletion()` to prevent stack overflow from circular references.

### 2. Progress Value Documentation (Critical)
Added documentation comment in `flow-plan.js:getPlanProgress()` explaining the different progress conventions:
- epics.json: 0-1 (decimal)
- features.json: 0-100 (percentage)
- plans.json: 0-100 (percentage)

### 3. Secure Entropy (High)
Replaced `Math.random()` with `crypto.randomBytes(8).toString('hex')` in all ID generation functions:
- `generateTaskId()`
- `generateEpicId()`
- `generateFeatureId()`
- `generatePlanId()`

### 4. Input Validation (High)
Added regex validation to `detectType()`:
- Length check (11-20 chars)
- Format validation: `/^(pl|ep|ft|wf)-[a-f0-9]{8}(-\d+)?$/i`
- Case-insensitive prefix matching

### 5. Unused Import (High)
Removed unused `color` import from flow-plan.js

### 6. Empty Feature Documentation (High)
Added documentation to `getFeatureProgress()` explaining that features with no stories return 0% progress (not 100%) because a feature needs completed work to be considered done.

### 7. Missing readJson Import (Bug Found During Fix)
Added missing `readJson` import to flow-done.js that was causing potential runtime errors.
