1. Search local files thoroughly (Glob, Grep)
2. Web search for current documentation
3. List assumptions and verify each
4. Cite sources for all claims
5. State confidence level (HIGH/MEDIUM/LOW)

**FORBIDDEN:** Claiming "X doesn't exist" without exhaustive search.
